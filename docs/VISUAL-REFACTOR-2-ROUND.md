# 视觉重构（第二阶段）：按四阶段重排页面结构（2026-09-24）

本轮**不是零碎 CSS 调整**，而是按用户给的方案重排了六个页面的结构与信息层级。
`src/core/**` 一行未改；没有新增依赖、字体、图片或外部素材；所有真实数据、路由与状态逻辑保持原样。

---

## 一、先统一 token（不是继续叠 override）

- `src/styles.css` 的 `:root` 仍是唯一 token 源。按用户给定的表**交换了底色命名**：
  `--bg: #F5F7F8`（页面背景）、`--bg-2: #FCFDFD`（表面：卡片 / 面板 / 顶栏）、`--bg-3: #EEF2F4`；
  同时把 68 处 `var(--bg)` / `var(--bg-2)` 引用一起交换，**视觉与交换前完全一致**（截图对比无差异），命名与方案一致。
- 其他 token 与上一轮一致：文字 `#16263D / #536274 / #7D8996`；品牌 `#1F4772`（soft `#E5EEF6` / line `#B7CBE0`）；
  状态 `#477A65 / #A66A35 / #A84F4F`；顶栏 64 / 侧栏 216 / 内容 1160 / 面板 340；字号 hero 40–76、page 30、section 21、paper 17、body 15.5、aux 13.5、meta 12；
  形状只有 12 / 8 / 胶囊三种；默认无大阴影、无渐变、无玻璃。
- 重复规则的清理：新增的排版组件集中在 `src/workbench.css`（组件层），`src/map.css` 只管地图页外壳，`src/demo-views.css` 只管首页与结果页，
  没有在文件末尾继续追加覆盖块（本轮对 workbench.css 是**整段重写**，不是叠加）。

## 二、四个阶段做了什么

### 阶段一：首页 + 论文集合

**首页（`LandingView.tsx` / `demo-views.css`）**
- 首屏改两列：左 56%（ResearchPilot → 论文方法梳理智能体 → 中文主张 → 一句 ≤24 字短说明 → 主按钮 + 次级文字链接），右 44% 是**当前案例的真实研究地图切片**：
  真实两个方法族、真实 5 个方法节点（按发表年份 = 研究顺序）、默认可见的真实关系（虚线 = 系统推断，620ms 绘制一次，首页唯一关系动效）；
  关系稀疏时写明「当前案例关系较少……系统不会补线把画布填满」。宽屏横向分栏、窄屏纵向分栏（保证节点文字仍是可读字号）。
- 首屏 700px（含顶栏 764px，落在 760–820 要求内），内容垂直居中，下方紧接第一个区块，不留无目的空白。
- 下方**只剩三个区块，三种不同版式**：①左说明 / 右真实论文目录（5 篇：短名 + 方法族 + 一句作用）；②左真实关系图 / 右说明 + 按钮（版式互换）；
  ③**通栏横向阅读路径**（前三步，编号只在这里出现，并标注「示例路线，尚未个性化」）。每个区块最多一个按钮、无 01/02/03 眉标题。
- 手机端：标题 → 说明 → 按钮 → 地图切片 → 三个区块依次排列，互不挤压。

**论文集合（`Library.tsx` / `workbench.css`）**
- 从「大卡片」改为**两层论文目录**：
  第一层 左（论文标题 / 方法标签 / 一句话作用）· 右（查看论文 / 更多操作）；
  第二层 当前分析状态 · 字段状态 · 实验数量 · 一行低权重元数据（方法族 + 来源）。
- 隐藏进详情：日期 / 页数 / 字符数 / arXiv、完整实验条件、完整关系列表、字段证据、程序校验问题；**「查看实验」也移进详情**，作为文字链接。
- 每行最多 1 个状态标签、最多 2 个操作入口；5 篇之间用细分隔线；只有展开的那篇用浅蓝底；普通行没有边框 + 阴影 + 底色叠加。
- 行高：典型 132–140px（两行英文原标题约 155px）；重新分析与移除论文仍在「更多操作」里，移除仍有两步确认 + 12 秒撤销。

### 阶段二：方法提取 + 阅读路线

**方法提取（`UploadFlowView.tsx`）**
- 顶部只保留**一条全局流程**（上传论文 → 解析文本 → 提取方法字段 → 校验原文证据 → 进入研究地图）。
- 下面改成左右两部分：左侧论文列表（每篇只显示名称 + 当前阶段 + 状态点，默认选中第一篇）；右侧只显示**当前这一篇**：
  论文名称、当前阶段、当前结果、字段数量、证据数量、下一步操作，**再往下才是完整时间线**（五步）与字段证据。
- 删除了每篇论文重复的完整五步条与重复状态标签；失败仍然写清失败阶段 / 原因 / 如何重试 / 已完成数据是否保留。

**阅读路线（`PlanView.tsx`）**
- 顶部只留：路线标题、示例路线状态、一句说明、一个主要按钮（条件表单默认收起成一行）。
- 主体五步 `01 ResNet → 02 ViT → 03 DeiT → 04 Swin → 05 ConvNeXt`（真实短名 + 年份），**默认不展开任何一步**：
  每步只显示方法名称 / 为什么现在读 / 重点看什么 / 下一步（不超过 4 行正文）。
- 点击某一步才展开完整内容（方法定位、原文依据、信息缺口、打开论文 / 在研究地图里看它）；同一时间只展开一步。
- 「候选方法」与执行可行性表放在整条路线之后；「示例路线，尚未根据用户偏好个性化。」仍在。

### 阶段三：研究地图 + 实验可比性

**研究地图（`MethodMap.tsx` / `MapView.tsx` / `map.css`）**
- **详情面板改成并列的一列**（`position: static`，宽 340px），不再绝对定位覆盖画布；实测面板打开时画布占 68.1%。
- 画布顶部显示**当前研究问题**（由真实关系生成，含证据状态与「去回答」）；问题从原来的引导条移到画布内。
- 画布高度改为按内容（不再用固定视口高度），关系少时不留大片空白；图例与缩放从画布内浮动改为画布下方一行。
- 工具栏只保留三个视图 + 一个主操作（按阅读路线继续）+ 选项（添加论文 / 重新加载 / 更换案例与三个筛选项都收进选项）。
- 节点只显示方法名 / 年份 / 一句贡献；选中后才在右侧面板显示完整做法、关系说明、证据状态与原文入口（原文全文默认收起）。
- 关系稀疏时仍如实说明（10 条真实关系里默认只画 2 条），不补假线。

**实验可比性（`ExperimentsView.tsx`）**
- 固定三部分：①结论卡（当前结论 + 一句原因 + 两个数值 + 查看原文证据）②条件矩阵（`条件 | 方法 A | 方法 B` 六行，状态用文字 + 小圆点，不再每格一个彩色胶囊）
  ③实验记录**按方法分组**（ResNet / ViT / DeiT / Swin / ConvNeXt），每组默认只显示 2 条，其余显示「展开本组剩余 N 条记录」。
- 实验行仍是分隔行（第一行模型 + 结果，第二行极短元数据，右侧状态），只有选中行有浅蓝底。
- 结论仍完全来自 `compareExperiments()`，页面不做排名、不给因果结论，也不默认展示全部 20 条记录。

### 阶段四：全站一致性

新增自动检查（`verify-visual.mjs`）逐页比对：页面标题字号（唯一值 30px）、左侧栏宽度（唯一值 216px）、顶部栏高度（唯一值 64px）、
每页实心主按钮 ≤1、无嵌套卡片、无横向滚动；手机端五个页面：品牌栏单行 ≤60px、`nowrap`、可见入口只有 1 个「更多」、无横向滚动。全部通过。

## 三、动效收敛

只保留三种：页面切换 200ms 淡入、详情展开 260ms、首页关系绘制 620ms。已移除逐项/逐标签动画与地图节点逐个入场动画；
全部只动 transform / opacity，并支持 `prefers-reduced-motion`。地图连线绘制仍按上一轮要求保留（属于「关系绘制」同一类）。
