## 三、动效（克制、一次、可关闭）

- 内容进入视口时做一次渐入：`opacity 0 → 1`、`translateY(14px) → 0`，0.55s；首屏四行文字依次延迟 60/110/160/210ms。
- 02 段的连线用 `stroke-dashoffset` 逐步描绘（0.9s），虚线图例随后淡入（0.7s 延迟 0.5s）。
- 只用 `IntersectionObserver` + CSS 过渡：**不劫持滚动、不锁定整屏、无持续漂移或循环动画**。
- 尊重系统设置：`@media (prefers-reduced-motion: reduce)` 下直接显示（实测 `opacity=1 / transform=none`）。
- 实测动效确实发生（线上）：

| 时刻 | 第二段透明度 | 是否已触发 | 连线 dashoffset | 虚线透明度 |
| --- | --- | --- | --- | --- |
| 滚动前 | 0 | 否 | 1 | 0 |
| 滚动 250ms | 0.995 | 是 | 0.334 | 0 |
| 滚动 1.8s | 1 | 是 | 0 | 1 |
