# 首页三组抽象视觉动画重做（2026-09-24 第五轮）

只改首页的 SVG / CSS 图形与动画；**工作页、`src/core/**`、真实分析逻辑与路由均未改**。没有外部图片、字体、组件或动画库。

## 一、统一视觉语言

- 图形作用域四档色（不改页面主题）：深墨蓝 `#172B45` / 品牌蓝 `#2D5B89` / 中浅蓝 `#8EAFCE` / 极浅蓝 `#D5E2EE`。
- 线宽三档：`0.8 / 1.5 / 2.5px`；节点三档：`6 / 10 / 18px`（分叉点用 22px）。
- viewBox 桌面端 640×360；窄屏用**同一组坐标转置 + 0.9 缩放**成纵向构图（不是等比缩小），并把最小档节点提到 8px 保证可辨。
- 动画只动 `opacity / transform / stroke-dashoffset`，全部只播一次；离开视口即回到完整静止画面；`prefers-reduced-motion` 直接静态。
- 不用渐变、发光、粒子、网格背景、玻璃拟态、大阴影、白卡片；三张图三种结构（分叉 / 汇聚再分组 / 单向前进）。

## 二、三张图各表达什么

| 图形 | 表达 | 初始状态 | 中间状态 | 最终状态 |
| --- | --- | --- | --- | --- |
| 首屏右侧（分叉生长） | 从一个起点线索出发，生长出可探索的研究地图 | 只有起点(18)、分叉点(22)、右上终点依次淡入 | 主路径从起点绘到分叉点 → 继续绘到右上 → 右中/右下两条辅助路径依次绘出 | 8 个节点 + 一条最深主路径（带箭头）+ 两条较浅辅助路径 + 两条极细线索；一颗光点沿主路径走到右上后消失 |
| 论文集合（散乱 → 汇聚 → 分组） | 许多论文被整理成两条技术线索 | 左侧 7 条长短不一的线索与 2 个小圆点依次淡入 | 线索向中央移动 → 中央三条向内弯曲的细线形成汇聚 → 上方技术线先绘出 | 上方 3 节点技术线（节点旁横线长度递增）+ 下方 3 节点较浅技术线，间距更大；三个小词：论文线索 / 方法归组 / 技术路线 |
| 阅读路线（单向前进） | 从起点沿着一条明确顺序逐步阅读 | 只有起点圆点 | 主路径逐段绘制，每经过一个停靠点该点放大并显示编号 | 01→05 五个停靠点 + 终点箭头，一条连续深墨蓝主线；另有一条极浅虚线只作背景（透明度 0.22、无节点） |

三个区块的构图互不相同：分叉 / 汇聚再分组 / 单向前进。首屏与区块二都用「分叉」，但首屏是 8 节点的全局生长图，区块二是 5 节点的局部图（更紧凑、一条开放末端），不会看起来像同一张图。

## 三、为什么不会被误认为真实关系

1. 图形里没有真实论文名、篇数、关系数、证据状态与实验数值。
2. 全部装饰 SVG 带 `aria-hidden="true"`；每个图形下方都有一行「概念示意，不代表当前案例的真实关系数量。」，页脚说明真实结果在研究地图与阅读路线页。
3. 阅读路线图里没有「原文明示 / 系统推断」这类线型图例，只有一条单向路线。
4. 断言兜底：e2e 会检查首页不出现 `ResNet/ViT/BERT/…` 与「篇论文 / 条关系 / 原文已说明 / 待核查」；走查会检查
   首屏「一个节点出发 ≥3 条路径」、论文集合「三个区域词且不是放射状」、阅读路线「01–05 编号 + 每个点最多 2 段相接 + 只有一条带箭头」。
