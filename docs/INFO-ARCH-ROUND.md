## 四、哪些复杂内容被隐藏到开发者入口（「更多」）

`更多` 页面提供（每个都是可点击卡片）：

1. 论文库（原始字段）——字段、实验条件与程序校验记录
2. 全部结果与条件（专业视图）——原「实验比较」页（左筛选 / 右结论）
3. 方法关系图（完整）——所有关系与三档证据状态
4. 阅读建议（完整版）——按条件生成阅读路线
5. 待调查问题
6. 跨论文比较（论文级）
7. 开发状态与记录——规则版本、缓存版本、验证范围、模型调用、运行日志
8. 设置——模型接口配置（密钥只存本机）

并且：**开发回归样例（旧 NLP）只能在「更多」里切换**，不出现在主流程；两套论文集合各自独立计数、独立计算关系与推荐。

## 五、比较结果页的最终结构（自上而下）

1. 居中问题：「这些结果，真的能直接比较吗？」+ 一行说明「下面是一组推荐比较（不是排名，也不代表谁更好）」。
2. **两个结果卡片**：方法 · 变体（如 DeiT · DeiT-B）、数据集（ImageNet-1K）、大号数值（81.8%）、指标名（top-1 accuracy）；中间「对比」分隔。
3. **大号结论**：状态短句（如「仍需确认」）+ 26px 结论句（「信息不足，不能直接判断谁更好。」）+ 一句人话原因（「两个结果的额外训练数据不同，分数差异不能直接归因于模型结构。」）。
4. **简单可视化**：一致 / 不同 / 仍需确认 三列对照（不出现长表格）。
5. **三个可折叠区域**：为什么这样判断 · 哪些条件不同（含条件对照表）· 查看原文依据（直接打开原文弹层）。
6. 底部动作：「换一组结果比较」（推荐组合 + 自己挑两个结果）与「看方法演进」。

## 六、方法演进页的最终结构

1. **一条演进路线**：ResNet → ViT → DeiT → Swin → ConvNeXt。
   每个节点只有：方法名 + 一句话贡献 + 一个标签。
   - ResNet：让更深的 CNN 更容易训练（起点）
   - ViT：把 Transformer 引入图像分类（系统推断）
   - DeiT：降低视觉 Transformer 的数据门槛（系统推断）
   - Swin：用窗口注意力处理高分辨率图像（系统推断）
   - ConvNeXt：重新设计现代 CNN（仍需确认）
   标签来自真实关系数据：`原文已说明 / 系统推断 / 仍需确认 / 未见原文说明`。
2. **点击节点**显示：它做了什么（核心思路原文摘要）、和前一个方法的关系（关系类型 + 状态 + 理由；没有依据时如实写「论文里没有直接说明两者的继承或改进关系（仍需确认）」）、原文依据（核心思路原文 / 关系依据原文，均可打开弹层）。
3. **底部**：「如果你刚开始学习，建议按这个顺序阅读」1–5 条，每条含先读原因、重点看什么、「查看依据」；顺序与理由来自真实阅读建议数据。

## 十、仍需注意

1. 结果页默认推荐的是「信息不足」的组合（DeiT-B vs ConvNeXt-T）——这是当前数据的真实结论；「口径不同」的例子（ResNet 错误率 vs 其他准确率）放在「换一组结果比较」里。
2. 宣传首页的示意图是静态示意（标注为「论文结果 A / B」），不是真实数据渲染，避免让人误以为是实时结果。
3. 「更多」里的专业视图仍保留完整字段与表格（面向评审），未做减法——这是有意的层次分工。
