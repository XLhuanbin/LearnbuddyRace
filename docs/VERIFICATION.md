## V11 第二阶段：不可比检测

规则计算，不依赖模型自评。以下结果均在**端到端走查的界面上实测**出现。

| 选择 | 总体结论 | 关键差异 |
| --- | --- | --- |
| 全部 5 篇 | **当前不能直接比较** | 数据集：`WMT 2014 En-De/En-Fr`（翻译）与 `GLUE/SQuAD/RACE` 等（语言理解）没有共同项；评价指标：`BLEU` 与 `F1/accuracy/EM` 无共同项；实验设置：`从头训练` vs `微调` 协议不重叠 |
| 仅 BERT + RoBERTa + DistilBERT | **只能有限比较** | 数据集部分重叠（共有 GLUE、SQuAD）；指标部分重叠（共有 F1/accuracy）；评估协议一致（都是微调）→ 实验设置可直接比较；数据划分与预训练模型存在差异 |
| 额外训练数据 | 可以直接比较 | 5 篇均报告为未使用额外数据（`none`），且引文可核验 |
| 算力/训练时长 | 信息不足，无法判断 | GPT-3 未报告可核验的算力信息 → 系统拒绝判断可运行性 |

条件维度结论表均带「原文证据 / 信息缺失 / 判定规则」三类依据，可逐条展开核对。

### 本轮发现并修复的缺陷

1. 资源可行性判定过乐观：缺显存/并行/配置证据时仍可能给出 `suitable` → 新增程序门槛（三条件同时成立）。
2. 我把「模型判定 suitable」在汇报中概括成「算力可行」（未经验证的折算）→ 已在报告中更正，并在界面上区分「模型判定」与「程序修正」。

5. 证据绑定在「同名键并存」时未真正绑定（分支结构导致）→ 重构为「先定位目标、再取证据」，并对类型冲突/无效引用/跨论文区分处理。
