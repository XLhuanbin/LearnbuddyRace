# 视觉审美重构（2026-09-24）

「安静的研究编辑部」方向：冷纸白底 + 深墨蓝 + 一个品牌强调色；绿/橙/红只表达真实状态。
本轮只改视觉与信息层级，**没有改** `src/core/**` 的任何解析、关系、证据、可比性、缓存与模型逻辑，也没有新增依赖或外部素材。

---

## 一、先统一 token，再改页面

`src/styles.css` 的 `:root` 被重写为唯一 token 源（之前散落在 4 个 css 里的观感差异都收敛到这里）：

| 类别 | token | 值 |
| --- | --- | --- |
| 底色 | `--bg` / `--bg-2` / `--bg-3` / `--bg-4` | `#FCFDFD` 表面 / `#F5F7F8` 页面 / `#EEF2F4` 次级 / `#E3E9ED` |
| 文字 | `--fg` / `--fg-2` / `--fg-3` | `#16263D` / `#536274` / `#7D8996` |
| 品牌 | `--accent` / `--accent-2` / `--accent-soft` / `--accent-line` | `#1F4772` / `#17395C` / `#E5EEF6` / `#B7CBE0` |
| 状态 | `--ok` / `--pending` / `--warn` / `--bad` / `--neutral` / `--purple` | `#477A65` / `#A66A35` / `#96601F` / `#A84F4F` / `#5B6B7C` / `#4E5C86` |
| 边框 | `--line` / `--line-2` | `rgba(22,38,61,.14)` / `rgba(22,38,61,.26)` |
| 字号 | `--fs-hero` / `--fs-page` / `--fs-section` / `--fs-paper` / `--fs-body` / `--fs-aux` / `--fs-meta` | 40–76 / 22–30 / 18–21 / 17 / 15.5 / 13.5 / 12 px |
| 行宽 | `--measure` | 44em（≈60–70 中文字符） |
| 形状 | `--radius` / `--radius-sm` / `--radius-lg` / `--radius-pill` | 12 / 8 / 12 / 胶囊 |
| 外壳 | `--topbar-h` / `--side-w` / `--content-max` / `--panel-w` | 64px / 216px / 1160px / 352px |
| 动效 | `--du-page` / `--du-expand` / `--du-reveal` / `--du-draw` | 200 / 260 / 500 / 620 ms |

- **铜色退役**：`--copper*` 四个变量保留名字但统一映射到品牌色，因此全站四处「米色 + 铜色」的用法一次性消失，没有逐个类名去改。
- **只有三种形状**：容器 12px、按钮与输入框 8px、状态标签用胶囊；`.radius-lg` 从 16 统一回 12。
- **卡片默认不加大阴影**：`--shadow-1/2` 降到 0.05/0.07 透明度，`.card` 去掉了阴影；没有层级意义的内容改用分隔线 / 留白 / 浅色分组。
- 标题统一 `text-wrap: balance`，长说明统一 `text-wrap: pretty`。

## 三、被改成列表 / 分隔区的卡片

| 原形态 | 现形态 | 结构 |
| --- | --- | --- |
| `.papercard`（等高卡片，带边框与阴影） | `.lrows > .lrow`（分隔行） | 左：标题 + 标签 + 一句话作用 / 中：状态 + 字段数 + 实验数 / 右：查看论文 + 查看实验 + 更多操作；行间只有 1px 分隔线，无圆角无阴影 |
| `.stepper`（每篇论文五段大步骤条） | `.flowbar`（全局一条）+ `.stepmini`（每行 5 个点） | 展开后才显示 `.lnrow` 明细行 |
| `.exprow2`（每条实验记录一张卡） | `.exprow3`（60px 行） | 分隔线 + 选中行浅蓝底；未选中行透明 |
| `.dimstrip`（维度网格卡） | `.dimtable`（两列对照表） | 维度 / 方法 A / 方法 B / 判断 |
| `.pathstep`（每步一张卡） | `.railstep`（编号 + 轨道 + 内容区） | 每步一个内容区，无嵌套 |
| `.lite` / `.card`（到处是卡片） | `.quiet-group`（一条顶边线 + 留白） | 只有通知类才保留细边框 |

## 四、统一的字号 / 颜色 / 间距

- **字号**：首页标题 76px（手机 40）→ 页面标题 30（22）→ 区块标题 21（18）→ 论文标题 17/16 → 正文 15.5 → 辅助 13.5 → 元数据 12。正文类元素一律 ≥14px（走查里对 `.pgsub`/`.lrow-role`/`.railstep .ln .v`/`.verdict-explain`/`.exprow3 .l1 .m`/`.field-value` 逐个断言）。
- **颜色**：只用品牌墨蓝做强调；绿/橙/红只出现在真实状态标签里。走查断言「页头彩色标签 ≤3 种」，实测每页 2–3 种。
- **间距**：4px 网格（沿用 `--space-2..6` = 8/12/16/20/24）+ 卡片 12px 内边距、区块 24px 节奏；主内容 1160px 居中，左右留白一致。
- **外壳**：顶栏 64px（走查断言 60–68）、侧栏 216px、内容 ≤1160px、详情面板 352px（走查断言 340–360）；手机端品牌栏单行 56px，只留 R + ResearchPilot + 一个「更多」（其余入口收进菜单）。
- **流程条不再每页重复**：完整五步流程只在「方法提取」；论文集合/研究地图/实验可比性/阅读路线用一行简短面包屑。
- **一个区域一个实心主按钮**：走查对每个页面断言「页头实心按钮数 ≤1」。

## 七、仍然存在的限制 / 待核查项

1. **模型接口仍未配置**：实时抽取、关系重算与个性化路线跑不了；页面显示的是缓存案例，界面处处标明。
2. **论文字段状态用的是核心词表**：四态为「可核验 / 待人工核对 / 未找到证据 / 缺失」（走查断言已按真实词表修正，之前脚本里写的是旧词「已核验 / 未提取到」）。
3. **论文行高**：正文行 114–135px；两行英文原标题的行会到 155px 左右。没有把标题硬截成一行——标题是识别论文的第一信息，截断的代价高于多出的十几像素。
4. **研究地图默认只画 2 条连线**：这组 10 条真实关系里 6 条「关系不明确」默认不画、2 条待核查默认隐藏，界面用一行小字如实说明；没有为了让画布更满而补线。
5. **实验可比性行的彩色 flag 被移除**：额外预训练 / 测试时增强 / 蒸馏 / 集成等信息仍可在「关键差异」与「完整条件」里看到，只是不再每一行都重复一遍。
6. `docs/` 中旧目录的截图（landing-redesign / map-editorial / polish-round 等）保留在本地，属于历史轮次记录，未回改。
