## 二、为什么不会被误认为真实论文关系

1. 四段图形**没有任何真实论文名、论文数量、关系数量、证据状态、实验数值**——只有圆点、曲线和一处品牌蓝强调。
2. 所有装饰 SVG 都带 `aria-hidden="true"`，屏幕阅读器不会朗读图形；功能说明完全由旁边文字承担。
3. 首屏图形下明确写「研究流程概念示意：从一组线索出发，形成可探索的地图」；页脚写明「以上配图为**产品概念示意**，不对应任何真实论文；真实的分组、关系与阅读顺序由研究地图与阅读路线页按证据状态呈现」。
4. 图形里没有做「原文明示 / 系统推断」这类线型图例——那属于工作页的证据表达，不在首页出现。
5. 断言层面也拦住了：e2e 新增「首页配图是概念示意，且不出现真实论文名 / 数量 / 证据状态」，一旦首页文本里出现 ResNet/ViT/… 或「篇论文 / 条关系 / 原文已说明 / 待核查」就会失败。

## 三、动效与响应式

- 首屏进入页面播放一次；下方三段在进入视口时播放，离开视口撤掉 `play` 类 → 立刻回到完整静止画面（向上滚回不会出现「空图」），再次进入可重播；全部 `animation-iteration-count: 1`，无无限循环（走查会断言）。
- `prefers-reduced-motion: reduce`：不加 `play` 类并关闭全部装饰动画，直接显示完整静态画面（走查用 CDP 模拟该媒体特性并截图验证：节点全部可见、路径全部画完、无 play）。
- 窄屏不是等比缩小：同一组坐标做**转置重排**（`fig-tall`，纵向构图），文字在前、图形在后，首屏与区块都不横向滚动。
- 图形静止状态即完整构图（路径 `stroke-dashoffset: 0`、节点 `opacity: 1` 为默认值），动画只是「再画一遍」。

## 四、文字分量

每个区块正文控制在一行；图形区最小高度 300px（实测 ≥300），区块间距 112px，仍是大留白、无白卡片。

## 六、仍然存在的限制

1. 四段图形是概念示意，与真实数据无对应关系；真实关系/证据仍需打开研究地图与阅读路线页查看。
2. 首屏图形尺寸按列宽自适应（1440 下约 522×367），未强制 540×380——因为要保持在 48% 列宽内不换行。
3. 窄屏用的是同一组坐标的转置重排（不是重新设计的构图），只是保证节点可辨、不横向滚动。
