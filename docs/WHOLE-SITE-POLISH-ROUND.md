# 整站体验精修（2026-09-24）

目标：让每个页面都精美、统一、容易理解，同时**不破坏现有真实逻辑与运行结果**。
本轮只改前端结构、信息层级、交互提示、响应式与动画；**没有改** `src/core` 的任何分析、关系、证据、可比性、缓存逻辑。

---

| 统一项 | 做法 | 位置 |

## 2. 各页解决了什么问题

### 首页（只做稳定性复查 + 补入口）
- 复查：品牌标题仍是自托管衬线 + `document.fonts.ready` 门控（只淡入、不改尺寸）→ 无字体跳变；滚动渐入**可逆**（进入视口淡入、离开反向淡出、滚回重播），实测三方切换通过。
- 新增：首屏下方给出**五个明确入口**（论文集合 / 方法提取 / 研究地图 / 实验可比性 / 阅读路线），与左侧导航同名同义。
- 手机端不出现横向溢出，主按钮仍在首屏内。

### 论文集合（原「论文库」）：清理「脏」和「杂」
- 顶部只留四件事：案例名称、论文数量、已完成分析数量、数据状态 + **一个主入口**「进入研究地图」。
- 每张卡片严格按 **① 标题 → ② 方法标签 → ③ 一句话说明它在研究链条中的作用 → ④ 当前分析状态 → ⑤ 一个主要操作**。
  「在研究链条里」整行来自**真实关系数据**（`relations`）：写明是「原文明示 / 系统推断 / 待核查」以及「有引文 / 无直接引文」；
  「关系不明确」的配对**不拿来当链条说明**（与地图默认不连线一致），会换成一句如实说明。
- 收进「查看论文」的：7 个字段与四态标签、实验条件表、程序校验问题、arXiv/页数/字符数（次要信息统一降权为一行小字）。
- 操作层级：页头一个实心主操作；卡片的「查看论文 / 查看实验」是次级按钮；**重新分析、移除论文收进「更多操作」折叠**。
- 移除有**两步确认**，移除后出现 12 秒**撤销条**，撤销会把论文与已有分析结果写回本机（不重新调用模型）。

### 方法提取（原「上传我的论文」）
- 把过程做成一条处理流程：**上传论文 → 解析文本 → 提取方法字段 → 校验原文证据 → 进入研究地图**（桌面横向、手机纵向）。
- 每一步都写清：状态（已完成 / 进行中 / 等待中 / 失败）+ 当前处理对象 + **已经得到的结果** + 下一步会产生什么。全页没有百分比，也没有只转圈不说话的「处理中」。
- 每篇论文的区域给出：论文名称、当前阶段、真实处理状态、已提取字段数、证据是否存在、下一步按钮。
- 失败时写清：**失败在哪一步 / 原因 / 如何重试 / 已完成的数据是否保留**（论文元数据、解析结果与上一次字段都保留）。

### 研究地图（保留结构，增强「同一个研究故事」的连续感）
- 新增：**研究主题说明**（取自语料集的 domain / purpose）、**关系总数与当前显示条数**（含隐藏原因计数）、关系类型图例（原有）、
  「**只看有证据关系**」筛选、**「按阅读路线继续」**入口。
- 「选择关系」时会给出**关系依据 / 证据强度 / 证据来源**。证据强度按三档表述（原文明示 / 系统推断 / 待核查），并明确写「本项目不使用置信度百分比」。
- 关系不足时：不补假线，改为**如实说明**「当前没有直接关系可画」+ 为什么（多少条「关系不明确」默认不画、多少条待核查默认隐藏、有没有绑定引文），并提示分栏仍按真实家族呈现、可点节点逐个看。
- 动画：节点按顺序轻微上浮淡入（0–440ms 错峰，放在子元素上，不影响选中弱化）；原文明示连线按路径长度**绘制一次**，系统推断/待核查的虚线沿方向**流动一次**；选择节点时相关连线短暂加粗。全部可被 `prefers-reduced-motion` 关闭。
- 手机端只保留：品牌、当前页、地图主体、主要问题说明、下一步入口。

### 实验可比性（原「全部结果与条件」）
- **结论优先**：首屏第一块就是结论卡（可以直接比较 / 条件不同，需要谨慎比较 / 信息不足 / 不能直接比较）+ 一句人话解释 + 「具体到这里」+ 两条记录的数值。
- 结论下面只列**六个关键维度**：评估集 / 输入分辨率 / 额外数据 / 预训练 / 测试时增强 / 单模型或集成，每格标明「一致 / 不同 / 未知」。
- 实验列表改成紧凑可扫描的行（不同结果不再等重：待核查的降权显示，右边给出行列核验计数）。
- 完整条件表、判断理由、注意事项、免责声明全部收进「查看完整条件差异与原文证据」折叠区。
- 页面直接写明「本页不做排名，也不给因果结论」；结论仍**完全来自 `compareExperiments()`**，页面没有自行推导任何新判断。

### 阅读路线（原「阅读建议」）
- 从「卡片列表」变成**一条连续的纵向路径**：圆形编号 + 竖线轨道 + 步骤卡。
- 每一步给出：论文与方法名（`0N · 短名`）、阶段词（方法家族 + 首个已抽取的技术策略，**不发明阶段结论**）、
  为什么现在读、重点看什么、原文依据（可直接打开）、读完后进入哪一步、以及「打开这篇论文 / 在研究地图里看它」两个入口。
- 未配置模型时明确写：**「示例路线，尚未根据用户偏好个性化。」**，并说明上方条件没有生效。
- 候选方法（为什么是这些方法）移到路径之后，理由/目标匹配/执行可行性/缺失信息全部保留，执行可行性表格默认展开并保留「论文证据判断 ≠ 实际执行验证」的说明。

## 3. 真实逻辑是否保持不变

- `src/core/**` 本轮**零改动**（含 `comparability.ts` / `experiments.ts` / `grouping.ts` / `validation` / `cache` / 模型调用）。
- 关系、证据状态、可比性结论、排名禁令、缓存/实时标注、未配置模型标注全部沿用原有判定，UI 只做呈现。
- 唯一新增的数据写入是「撤销移除」：把被移除的论文与已有分析结果**写回本机**，不触发任何模型调用。
- 页面改名（论文库→论文集合、上传我的论文→方法提取、全部结果与条件→实验可比性、阅读建议→阅读路线）同步更新了 `MoreView` 卡片标题与走查脚本断言。

## 5. 仍然存在的限制 / 待核查项

1. **模型接口仍未配置**（`api.deepseek.com` 密钥余额问题未解除）：实时抽取、关系重算、个性化路线仍无法跑；页面显示的仍是**缓存案例**，界面处处标明。
2. **「只看有证据关系」在当前视觉语料下会得到空画布**：这组 10 条关系没有一条绑定可核验引文（4 条待核查、其余为系统推断 / 关系不明确）。这是真实状态，页面按「当前没有直接关系可画」如实说明，没有补线。
3. **「方法提取」导航项目前指向「上传论文」流程页**（不新增路由），页面标题已统一为「方法提取」。
4. `docs/` 里的旧截图目录仍保留在本地（仓库忽略 `docs/**/*.png`），文案中提到的旧页面名（论文库 / 阅读建议）属于历史记录，未回改。
5. 手机端品牌栏在 390 宽会折成两行（约 100px），这是为了让「缓存案例 / 使用说明 / 更多 / 设置」都保持可点；如需更矮可以只留图标，但会牺牲可读性。
