# 定点视觉重构（2026-09-24 第三轮）

保留首页左侧品牌方向，重点重做：① 首页右侧「研究脉络预览」 ② 首页下方三个介绍区块 ③ 所有工作页的信息层级与默认状态。
不动 `src/core/**`；不新增依赖/字体/图片；所有图形继续使用真实数据，不编造关系。

---

## 一、首页右侧：研究脉络预览（不再是完整地图缩略图）

- **一个容器**：520–560 × 320–360（实测 522 × 344）、圆角 12px、只有一条边框、无重阴影；不再出现「卡片里套卡片」。
- **顶部**：左「研究地图预览」，右「5 篇论文 · 2 条可见关系」（篇数取真实论文数，关系数取默认可见关系数——与图中连线条数一致）。
- **两条研究轨道**：Transformer 架构 / 卷积网络（CNN），轨道只用一条细线 + 标签 + 篇数，不是卡片。
- **节点** 148×70：方法名 15px、年份 12.5px、不再放长贡献描述；**有真实关系的节点用浅蓝底**，其余用普通底。
- **连线**：只画默认可见的真实关系（当前 2 条）；画在节点之前（实测图层顺序在节点之下，不会被遮挡）；
  同轨道走节点下方弧线（弧深 30/42 随索引错开）、跨轨道走两轨之间的 S 形；带箭头、不用大弯曲；
  线型按证据状态区分：原文明示实线、系统推断虚线、待核查点划线。
- **底部一句话**：「图中只显示当前可见的真实关系，其余关系仍需核查。」不再出现「10 条关系」这类与图不一致的说法。
- 宽屏横向、窄屏自动切纵向（节点与文字不缩小到看不清）。

## 二、首页首屏与下方三个区块

- 首屏左右 52% / 48%、间距 72px、两列垂直居中，右侧垂直中心与中文主标题/按钮区对齐；顶部不再有大片空白。
- 三个区块：标题 26–32px（实测 30px）、正文 17px、区块间距 112px、图形最小高度 260px、每块一句说明 + 最多一个按钮。
  ① 左标题 / 右真实方法族（族名 + 篇数 + 短名，用分隔线与留白，不套卡片）
  ② 左真实关系预览 / 右标题（两条真实关系，线型与地图一致）
  ③ 左真实前三步阅读路线 / 右标题（编号只在这里出现，并标注「示例路线，尚未个性化」）。

## 三、工作页统一清理

- **顶部栏**：左侧 R 图标 + ResearchPilot + **当前案例名称**（原来这里是标语），右侧只有 缓存状态 / 使用说明 / 更多 / 设置，文字 13–14px。
- **侧栏**：只突出五个主要任务；「专业视图」（方法关系图 / 待调查问题 / 跨论文比较）与「开发」（开发状态 / 设置）默认折叠，展开后仍是普通文字导航。
- **论文集合**：改成三行结构 —— 第一行 论文短标题（真实方法短名，完整标题在悬停与展开区）+ 方法族 + 查看论文 / 更多操作；
  第二行 一句话作用 + 当前状态 + 实验数量；第三行点击后展开：完整标题、arXiv、页数、字符数、字段证据、实验条件、程序校验、查看实验。
  行高实测 118px（要求 108–130），行间只有 1px 分隔线。
- **方法提取**：左列表（名称 + 当前阶段 + 状态点）+ 右当前论文详情，新增「已完成步骤」一行；默认只展开第一篇。
- **实验可比性**：条件表恢复四列「条件 | 方法 A | 方法 B | 判断」，判断用文字 + 小圆点；结论区只保留**一个**原文证据按钮。
- **阅读路线**：默认五个节点都收起，点击才展开当前节点。
- **研究地图**：两个方法族靠近中间（分栏间距 152 → 96，中心距 346px），画布高度锁定 520–600px，默认不打开右侧详情面板。

## 五、仍然存在的限制

1. 模型接口未配置：实时抽取、关系重算、个性化路线仍跑不了，页面显示缓存案例并标明。
2. 首页预览只画默认可见的 2 条真实关系；其余是「关系不明确」或待核查，按口径不画，也不补线。
3. 论文行用真实方法短名做标题，完整英文标题放在悬停提示与展开区（避免长标题把行高撑破 130px）。
4. 实验记录仍按方法分组、每组默认 2 条，全部记录可展开查看。
