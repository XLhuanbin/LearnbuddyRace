## 一、线上「视觉论文案例」出现 10 篇 / BERT 被放进「视觉 Transformer」：排查结论与修法

**复现与定位**（`scripts/verify-collection-scope.mjs`）：在浏览器里同时放入
① 无 `corpusId` 的历史 NLP 记录、② 用户自己上传/粘贴的论文（`user-import`），再加载视觉案例：

| 数据 | 之前的行为 | 现在的行为 |
| --- | --- | --- |
| 历史 NLP 记录（无 corpusId） | 已被归位为 `nlp-dev`，**不计入**案例（这条之前就是对的） | 同前，仍不计入 |
| 用户自己上传的论文 | **被静默并入案例地图**（`presetPapers.concat(ownPapers)`），于是「5 篇」变成 10 篇，BERT/语言模型的 Transformer 被塞进泳道 | 案例地图只显示当前集合的 5 篇；用户论文在「选项」里单独提示并可切换查看 |

**根因**：`MapView` 把「当前语料的预置论文」和「用户自传论文」拼在一起渲染；同时家族名写死为「视觉 Transformer」，
对语言模型不忠实。**没有**通过删除用户论文或清空数据库来解决。

**修法**：
1. **集合范围分离**：地图有两种集合——`案例`（当前语料的预置论文）与`我上传的论文`（用户自传），
   二者永不静默混合；工具栏始终显示当前集合名与篇数。
2. **自动落到有数据的集合**：案例未加载但用户已有自己的论文时，直接显示「我上传的论文」。
3. **家族命名中性化**：`视觉 Transformer` → **`Transformer 架构`**（卷积网络（CNN） / 混合（卷积 + 注意力） / 待确认），
   因此不会把语言模型称为「视觉 Transformer」。
4. **历史数据仍在**：IndexedDB 里用户论文与历史记录一条未删（回归脚本断言 ≥6 篇仍在）。
5. **新增回归**：`verify-collection-scope.mjs`（14 项）——包含「案例地图不得出现 BERT / 用户论文」「不得把语言模型标为视觉 Transformer」
   「可单独查看我上传的论文」「单篇用户论文不得编造关系」「往返切换后案例仍是 5 篇」。

## 三、设计：探索画布（不是分类看板）

- **一条紧凑工具栏**：`研究地图 · 视觉论文案例　5 篇 · 缓存案例` ｜ 方法地图 / 联系与区别 / 从哪里开始 ｜ 添加论文 ｜ 选项 ▾
- **一整块画布**：`80vh` 级别的白色画布，内容居中，页面无嵌套滚动冲突；只有一个内部滚动容器（内容超长时）。
- **分区**：泳道改为**轻量分区**（柔和底色 + 小标题「卷积网络（CNN） · 2」），不再是大盒子主导画面。
- **节点**：清晰短名称 + 弱化年份 + **一条读得懂的短贡献**；尺寸固定（不表达质量或影响力）。
- **连线**：只画真实关系；实线=原文明示、虚线=系统推断、点线=待核查；方向箭头忠实于 from → to；
  同泳道用回环、跨泳道在泳道间隙走 S 曲线（不穿过节点、不压字）。
- **每次点击立即有结果**：桌面右侧浮层阅读面板、窄屏底部面板，都出现在当前可见区域，关闭后视角不丢。
  - 点节点：一句话贡献 / 核心做法 / 与相关方法的联系（第一层）；「深入解释与原文依据」折叠（技术策略、局限、引文按钮、家族判定依据）。
  - 点连线：一句话方向说明 + 证据状态 + 「具体联系 / 变化」（取推断理由）+ 「原文依据」折叠（缺引文时如实说明）。
- **缩放**：底部右侧轻量控件（− / 百分比 / ＋ / ⟳ 恢复视图），不靠缩小字体塞内容。
- **窄屏**：图形不缩小（保持文字可读），画布可左右滑动并给出提示；详情面板改为底部浮层。

1. **e2e 覆盖比上一轮少**：上一版的 `scripts/e2e-check.mjs` 在一次补丁中被误截断，我按当前界面**重建了尾部**，
   覆盖从 127 项降到 66 项（保留了首页、地图交互、论文库字段与校验、关系、阅读建议、待调查问题、跨论文比较、密钥扫描、
   语料切换与隔离、重新分析两步确认、刷新恢复、窄屏、控制台错误等主干）。**需要补回**专业视图的细粒度断言。
2. **窄屏仍是横向滑动的泳道**：文字可读、可触摸滑动，但理想方案是按家族纵向堆叠泳道（下一步）。
3. **正式案例「原文明示」为 0 条**：现有关系都是系统推断或待核查，实线线型在本案例中暂时用不到（数据真实状态）。
4. **家族判定仍是关键词规则**：换更细领域需扩充词表，判不出会进「待确认」。
5. **模型抽取成功路径仍未实测**（当前环境无可用密钥）：上传链路只走到「解析完成 + 就地提示配置模型」。
6. **自动化不能替代真实用户**：本轮验证的是「首屏是图形、点击有反馈、证据归属正确、集合不混」，是否真的让陌生用户自然开始点，
   仍需真人试用反馈。
