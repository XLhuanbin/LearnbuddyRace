这与上一轮程序强制降级的结论一致 —— 说明**提示词的严格标准与程序的校验标准已经对齐**，不再靠事后降级兜底。

## 二、发现并修复的真实缺陷：推荐理由的证据挂载

重跑后检查决策输出，发现 5 条「资源类理由」全部被标成「该理由没有可核验的证据支持」，但算力条件其实都已通过校验。

**根因**：模型把条件维度写成了 `evidenceRef.kind = "field"`（例如 `field:computeResources`），
而程序只按 `kind === "condition"` 才去条件里取证据 → 查不到 → 误判为无证据。

**修复**：不再按 `kind` 过滤，而是在「字段」与「条件」两处都查，key 命中且证据通过校验就挂上（`analyze.ts`）。

| 项 | 修复前 | 修复后 |
| --- | --- | --- |
| 有证据的推荐理由 | — （5 条资源理由被判无证据） | **15 条**（其中资源类 5 条全部绑定算力条件） |
| 被标「无证据」的理由 | 6 条（含 5 条误判） | **1 条**（真实缺证据：RoBERTa 的 datasets 条目引文未通过校验） |
| 资源类理由是否带阶段 | 否 | **是**：`算力阶段：从头预训练 / 微调 / 从随机初始化训练` |

修复后的推荐示例（BERT）：理由写明「论文报告的算力条目明确对应**微调阶段**：单块 Cloud TPU 最多 1 小时，或 GPU 几小时，这是用户两周内可尝试的」，
并把「论文未报告**从头预训练**阶段的算力」写入缺失信息 —— 不再把预训练成本与微调成本混在一起比较。

## 三、剩余验收项的执行结果

### 3.1 推荐随用户条件变化（`npm run variation`）—— **已完成**

两组条件各跑一次真实决策：

| | 条件 A：笔记本、无 GPU、两周 | 条件 B：8 卡 A100、半年 |
| --- | --- | --- |
| 阅读顺序 | Transformer → BERT → DistilBERT → RoBERTa → GPT-3 | **BERT → RoBERTa → DistilBERT → Transformer → GPT-3** |
| 候选匹配度 | BERT=suitable，其余 conditional/unknown | **BERT=suitable、RoBERTa 由 conditional 变为 suitable** |
| 解释 | — | RoBERTa 的算力条目（1024×V100 约一天）在 B 条件下变得可行，因此匹配度上升；Transformer 从第 1 位降到第 4 位（用户已具备基础） |

结论：**阅读顺序与候选匹配度都随条件发生了有依据的变化**（`npm run variation` 输出 `阅读顺序是否变化=true，候选匹配度是否变化=true`）。
完整对照见 [`DECISION-VARIATION.md`](DECISION-VARIATION.md)。

### 3.2 未预置论文的真实导入验证 —— **已完成**

用一篇**不在预置语料中**的论文（*Denoising Diffusion Probabilistic Models*, arXiv 2006.11239，25 页，与预置的 5 篇语言模型论文不同领域）走完整条链路：

```bash
node scripts/import-verify.mjs --pdf samples/pdfs/2006.11239.pdf
```

| 项 | 结果 |
| --- | --- |
| 解析 | 25 页 / 57,483 字符，无文本层检查通过 |
| 字段 | **7/7 可核验**，全部带页码（p.1~p.13） |
| 典型抽取 | 方法名 `diffusion probabilistic models`、数据集 `CIFAR10, LSUN, CelebA-HQ`、指标 `Inception score, FID, NLL, rate, distortion`（均正确） |
| 实验条件 | 6/9 可核验（预训练语料 / 下游额外数据 / 数据增强三项因引文未通过定位而标为待人工核对） |
| 与预置论文可比性 | 与 5 篇语言模型论文均为**当前不能直接比较**（图像生成 vs 语言理解，数据集与指标无共同项）—— 符合预期 |
| 是否写入参赛语料 | **否**。只生成验证记录 [`IMPORT-VERIFICATION.md`](IMPORT-VERIFICATION.md)，预置语料仍是固定的 5 篇 |

**这次验证又暴露一个真实缺陷**：该论文的启发式标题抓到了摘要句子
（`a class of latent variable models inspired by considerations from nonequilibrium thermodynamics. Our best results…`），
而模型给出的标题**也是同一句**（因为它确实出现在原文中，能通过「引文可定位」校验）。

修复：新增 `looksLikeTitle`（长度、词数、句末标点、摘要起始词等判定）。
模型标题不通过则该标题不被采用，论文标记为 `titleFrom = 'unverified'`，
界面显示「**标题未确认（首页文本不像标题，请人工核对）**」，并产出校验问题 `title_unverified`。
该论文的验证记录里确实出现了这条提示，说明整条「不确定就标出来」的链路是通的。
